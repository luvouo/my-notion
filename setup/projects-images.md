# Projects 이미지 붙여넣기 설정

기존 위젯이 사용하는 Supabase 프로젝트에서 한 번 설정합니다. 기존 일정·프로젝트 데이터는 수정하지 않습니다.

1. Supabase 대시보드에서 기존 프로젝트를 엽니다. 프로젝트 ID는 `oegiiszccisrrbeevdhm`입니다.
2. **SQL Editor → New query**를 엽니다.
3. 이 폴더의 `projects-images.sql` 내용 전체를 붙여 넣고 **Run**을 누릅니다.
4. Projects 위젯을 새로고침합니다. Objective·Notes·Report에 복사한 이미지를 붙여넣거나 **+ 이미지**로 파일을 선택합니다.

- PNG·JPG·WebP, 원본 최대 20MB를 지원합니다. 긴 변 2,000px 이내의 WebP로 자동 변환합니다. WebP 변환을 지원하지 않는 모바일 환경에서는 PNG 또는 JPG로 전송합니다. PNG는 투명 배경을 유지하며, 전송 파일이 6MB를 넘으면 크기를 추가로 줄입니다.
- 이미지 너비는 25·50·75·100%로 바꿀 수 있습니다. 좁은 화면에서는 본문 너비에 맞춥니다.
- Objective·Notes는 자동 저장하며 Report는 **Save**를 눌러 저장합니다.
- 전송 실패 시 **재시도**를 누릅니다. 브라우저에서 임시 저장을 허용하면 새로고침 후에도 전송 대기 이미지가 남습니다. 서버에 전송되기 전에는 다른 기기에 표시되지 않습니다.
- 이미지 삭제는 본문에서 제거하는 동작입니다. Archive와 다른 기록에서 사용하는 서버 파일은 삭제하지 않습니다.
- 기존 Markdown Export에는 텍스트와 `[이미지]` 표시가 포함됩니다. 이미지 파일 자체는 포함되지 않습니다.

`project-images`는 비공개 저장소입니다. 같은 위젯 패스코드로 연결된 저장 공간의 이미지에만 접근하도록 구성합니다. 별도 공개 URL이나 만료되는 이미지 주소를 프로젝트 데이터에 저장하지 않습니다. 공개 버킷이나 서비스 역할 키는 필요하지 않습니다.

이미지 저장소를 이전 버전으로 설정한 경우 `projects-images-mobile.sql`을 한 번 실행하면 모바일의 PNG·JPG 전송을 지원합니다. 접근 대상·패스코드 확인·비공개 설정·6MB 제한은 유지합니다. 기존에 전송을 기다리는 이미지도 같은 참조 경로로 재시도합니다.
